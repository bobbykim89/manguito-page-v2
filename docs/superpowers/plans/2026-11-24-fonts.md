# Custom Fonts Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Inter becomes the base font on every page, Permanent Marker shows where `font-marker` is used, and both are self-hosted from Fontsource packages with no font service involved.

**Architecture:** `styles.css` renames the theme variables to Tailwind 4's `--font-*` namespace and makes Inter `--font-sans`. `nuxt.config.ts` gives `@nuxt/fonts` the two families from its `npm` provider (the `@fontsource/*` packages) and turns the network providers off. The module copies the files to `/_fonts/` and writes the `@font-face` and fallback rules.

**Tech Stack:** Tailwind 4 `@theme`, `@nuxt/fonts` 1.2.0, `@fontsource/inter` and `@fontsource/permanent-marker` 5.3.0, Vitest (`unit` and `api`).

**Spec:** `docs/superpowers/specs/2026-11-24-fonts-design.md`

## Global Constraints

- **Inter:** weights 300, 400, 600, 700. **Permanent Marker:** weight 400.
- The two packages are added as exact-version dependencies. No `allowBuilds` change.
- No network font provider may be used, in dev, build or tests.
- Keep `font-display: swap` (the module default) and the module's fallback faces.
- No changes to font sizes, weights or which elements use the marker font.
- Commits follow Conventional Commits with a path scope and end with `Co-Authored-By: Claude Opus 5.5 <noreply@anthropic.com>`.

## Review Focus

1. **A weight the site uses but the config omits** (`font-light` 300 on `/posts`) would fall back to a synthesised weight. Pinned in Task 2: the test expects one Inter face for each of the four weights.
2. **A `src` URL that points at a remote host** (Google, Bunny) would mean a provider was used. Pinned in Task 2: every `src` must start with `/_fonts/`.
3. **A face whose file isn't actually emitted** gives a 404 and invisible-text fallback. Pinned in Task 2: one `src` per family is fetched and returns 200 with a font content type.
4. **Elements with their own `font-family`** (theme headings, form inputs) might not inherit Inter. Pinned in Task 2's walk: the computed `font-family` of `body`, `h1`, `button` and `input` on the walked pages starts with Inter.
5. **Accessibility and hydration** must not regress. Pinned in Task 2's walk: axe and the hydration-warning check stay at 0.
